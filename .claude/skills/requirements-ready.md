# Ready for Development Assessment

## Context
- Ready for Development config: `team-generated/ready-for-development.md`
- Requirements rules: `team-generated/requirements-rules.md`
- Workflow gates: `team-generated/workflow-gates.md`
- Output language: English

## Important
Formal team readiness criteria are NOT DEFINED (BA confirmed, 2026-09-29).
Do not invent criteria. Do not issue a READY / NOT READY verdict.
Run quality checks and report gaps only.

## Steps
1. Run quality review if no current review exists for this artifact.
2. Check configured BA working checkpoints are closed (intake approved, spec approved, stories/AC approved).
3. List unresolved dependencies and blocking questions.
4. Report human-gate status.

## Output structure
- **Quality findings** (from quality-review skill or summary)
- **Configured human-gate status** (intake / spec / stories/AC approvals)
- **Unresolved dependencies**
- **Blocking questions**
- **Statement: FORMAL READINESS CRITERIA NOT DEFINED**
- *(No READY / NOT READY verdict)*
