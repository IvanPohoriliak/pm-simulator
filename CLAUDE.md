# PM Simulator

This repository includes a **Requirements Assistant** for PM Simulator requirements work.

## Starting requirements work

Describe what you need in plain language — for example:
- "I want to add a new feature to the simulator"
- "Help me write a requirement for X"
- "Review this spec"
- "Break this into stories"
- "Publish to GitHub Issues"

The assistant will route your request to the right skill automatically.
